# Contributing

Thanks for helping keep this directory useful and source-backed.

## Add or update an entry

Please open an issue or pull request with:

1. The provider's official developer-documentation URL.
2. A concise factual description supported by that documentation.
3. One directory category from the README.
4. The documented interface type: `REST`, `GraphQL`, `MCP`, or `API` when a more precise public classification is unavailable.

## Editorial rules

- Link to official documentation, not pricing pages, reseller pages, affiliate links, or search results.
- Use the provider's official name and avoid marketing claims, rankings, prices, availability guarantees, or compatibility claims that the documentation does not establish.
- Add an independent provider once at its most useful canonical documentation URL.
- Keep descriptions short, neutral, and traceable to the linked source.
- Do not submit API keys, credentials, private endpoints, screenshots containing account data, or unverified claims.

For removals, include the existing URL and a brief reason such as a moved or retired documentation page.
